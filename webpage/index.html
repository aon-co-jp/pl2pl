できること / What it does

コマンド内容 / What
pl2pl phpPHP (Laravel / Symfony) → FastAPI
pl2pl webJava・COBOL・PHP・Flask/Django を自動で見分けて変換 / auto-detects and converts
pl2pl ir(試作 / prototype) PHP・Python・Java のルート → JSON / OpenAPI
pl2pl watch言語・フレームワークの新しい版へ自動で追いつく / keeps up with new versions
pl2pl cobol / omp / kokkos / cport / pyhpcCOBOL・C/C++・Python の移植と高速化 / porting and speed-ups

変換できない所は、黙って消さずに TODO として残し、理由を報告書に書きます。 / Anything that cannot be converted is left as a TODO with a reason in the report.

設計思想(メリット・デメリット) / Design principles (pros and cons)

画面: WASM と tokio、HTML5・CSS3 は最小限 / UI with WASM and tokio · Node.js・JavaScript・TypeScript を使わない設計 / No Node.js, JavaScript, TypeScript · JSON は RS-JSON / JSON with RS-JSON · REST 全廃、Connect と gRPC / Connect and gRPC instead of REST · 共有基盤を1回だけ入れる / Shared base, installed once
