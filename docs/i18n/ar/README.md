# pl2pl

## ما هو pl2pl؟
تُكتب البرامج بلغات كثيرة (لغات البرمجة).
**pl2pl أداة تعيد كتابة برنامج من لغة إلى لغة أخرى.**
فمثلًا يستطيع تحويل موقع مكتوب بـ PHP (Laravel) إلى موقع مكتوب بـ Python (FastAPI).
يعمل على Windows وLinux وMac (الإصدار 0.1.0، ما زال قيد البناء).

- تثبّته على حاسوبك. الموقع الإلكتروني فيه الشروحات والتنزيلات فقط → <https://easy-web.tokyo/pl2pl/>
- إذا لم يستطع pl2pl إعادة كتابة شيء ما، فلا يخفيه. يترك `TODO` (ملاحظة لوقت لاحق) ويذكر السبب في تقرير.
- هدفنا: إعادة الكتابة بين أكبر عدد ممكن من اللغات المعروفة.

## ما يستطيع فعله الآن
| الأمر | ماذا يفعل |
|---|---|
| `pl2pl php` | PHP (Laravel / Symfony) → FastAPI. المزيد في [PHP.md](../../PHP.md) (باليابانية) |
| `pl2pl web` | يفحص مجلدًا، ويتعرّف على Java وCOBOL وPHP وFlask/Django، ويسلّم كلًّا منها إلى الأداة المناسبة |
| `pl2pl ir` | (نسخة تجريبية) يضع «المسارات» (routes) في PHP وPython وJava في شكل واحد، ثم ينتج JSON أو OpenAPI أو هيكلًا أوليًّا لـ FastAPI. وتحويل PHP يحمّل أيضًا الأنواع وأجسام الدوال والنماذج والوسائط البرمجية (middleware) والقوالب في هذا الشكل قبل الكتابة |
| `pl2pl watch` | يكتشف الإصدارات الجديدة للغات والأدوات ويلحق بها تلقائيًّا |
| `pl2pl cobol` | COBOL + JCL → GnuCOBOL (Linux) |
| `pl2pl omp` / `kokkos` / `gpu` | يجعل حلقات C/C++ أسرع (gpu نسخة تجريبية) |
| `pl2pl cport` | يجعل شيفرة C الخاصة بـ UNIX تعمل على Windows وLinux معًا |
| `pl2pl pyhpc` | يجعل العمليات الحسابية في Python أسرع باستخدام Numba |
| `pl2pl llm setup` | يثبّت مساعد الذكاء الاصطناعي (aruaru-llm). لم نتحقق بعدُ من التثبيت الفعلي |

## اللحاق بالإصدارات الجديدة تلقائيًّا
نشغّل `pl2pl watch` كل ليلة وكل صباح.
1. يتحقق من صدور إصدارات جديدة للغات والأدوات (القائمة في `registry/ecosystem.toml`).
2. يجري الاختبارات بالإصدار الجديد. فإذا نجحت، حدّث «الإصدار المدعوم» بنفسه.
3. وإذا فشلت، يحاول version-control (بمساعدة الذكاء الاصطناعي) إصلاح المشكلة.
4. وإن تعذّر الإصلاح، يرسل رسالة إلى عناوين البريد الإلكتروني وحسابات LINE المحفوظة.

تنبيه: في laravel وsymfony وflask وdjango وبعض الأدوات الأخرى، يكتفي حاليًّا بالقول «صدر إصدار جديد».
وعلى GitHub تُجرى أيضًا اختبارات بأحدث الإصدارات تلقائيًّا كل ليلة وكل صباح.

## طريقة الاستخدام
```
pl2pl php ./myapp --out ./out
pl2pl web ./project --target fastapi --out ./out
pl2pl ir ./project --out ./out --format openapi
```

## أشياء مفيدة للعلم
- pl2pl حذر. إذا بدا شيء ما محفوفًا بالمخاطر، تركه كما هو وأخبرك بالسبب. ولا نَعِد بالسرعة.
- لم نجرّبه إلا على نماذج صغيرة. ولم نجرّبه بعدُ على برامج حقيقية كبيرة.

## ما الخطوة التالية
- وضع الأنواع وأجسام الدوال في الشكل المشترك أيضًا، وتمرير مخرجات FastAPI عبره.
- PHP: أجزاء Blade المكتوبة على هيئة أصناف (classes).
- التحقق من تنبيهات البريد الإلكتروني الفعلية ومن الإصلاح التلقائي بالذكاء الاصطناعي.
- التحقق من التشغيل على وحدة معالجة الرسوميات GPU (open-cuda / open-directx).

## الجديد في v0.2.0
- اختر تركيبتك بنفسك: `pl2pl web <dir> --backend <rust-axum|rust-poem|fastapi|mfastapi|rpoem|rporea> [--frontend bootstrap-ts|rust-wasm|none] [--db none|mysql|mariadb|postgres|sqlite] --out <dir>`. يُعاد كتابة COBOL؛ أما C وC++ وFortran فتبقى تعمل كما هي ويستدعيها الويب.
- يكتب `pl2pl c2rust` (لـ C وC++ البسيطتين) و`pl2pl f2rust` (لـ Fortran البسيطة) شيفرة Rust. ويُنشئ `pl2pl cobol --os <linux|macos|unix|windows>` سكربت بناء لـ GnuCOBOL.

## الجديد في v0.2.1 (2026-11-20)
- عند اختيار `rpoem` / `rporea` في `pl2pl web --backend` تظهر تنبيهات (باليابانية والإنجليزية): RPoem يتضمّن أصلًا ميزات متوافقة مع Tauri ومع WunderGraph Cosmo، إضافةً إلى tokio وWASM، فلا تختَرْها؛ ويُستخدم HTML5 وCSS3 لكن بأقل قدر ممكن؛ ولا تُستخدم JavaScript ولا TypeScript ولا Node.js ولا REST بحكم التصميم. وما يُضاف بـ `--also` وهو مضمَّن أصلًا يُرفض (رمز الخروج 2)؛ وما هو مضمَّن لكنه لم ينضج بعدُ يبقى قابلًا للاختيار مع تحذير.
- يحكم `pl2pl maturity [--repo DIR] [--llm URL] [--apply]` على هذا النضج بتشغيل اختبارات فحص (السجل: `registry/maturity.toml`). ورأي الذكاء الاصطناعي من aruaru-llm لا يغيّر الحكم وحده أبدًا.
- مع التركيبات غير RPoem / RPoRea يُقبل `--also nodejs` (أو `next.js`) مع تنبيه: نحن لا نفرض سياستنا في عدم استخدام Node.js، لكننا لا ننصح به. وتُعرض بدائل للّغة المختارة (RPoem / RPoRea + Reaxt، وFastAPI + Jinja2، وRS-Node.js، وأخرى لم نتحقق منها).
- المستودعات الشقيقة تُطوَّر معًا: Reaxt وRPoRea وRPoem وRMojo وopen-cosmo وRS-TypeScript وRS-JavaScript وRS-Node.js وpl2pl. وعند تغيّر أحدها تُفحص البقية في اليوم نفسه.
- يشرح `pl2pl info [ui|nojs|json|connect|shared] [--lang ...]` و`webpage/info.html` مبادئ تصميم RPoRea / RPoem مع المزايا والعيوب بـ 11 لغة.
- بقي `COBOL_to` / `Java_to` الأصليان (لم يُحذفا)؛ وأعطت النسخ المدمجة في `converters/` مخرجات مطابقة.
