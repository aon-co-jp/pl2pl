# pl2pl

## pl2pl چیست؟
برنامه‌ها به «زبان»های گوناگون (زبان‌های برنامه‌نویسی) نوشته می‌شوند.
**pl2pl ابزاری است که برنامه‌ای را از یک زبان به زبان دیگر بازنویسی می‌کند.**
برای مثال می‌تواند وب‌سایتی ساخته‌شده با PHP (Laravel) را به وب‌سایتی با Python (FastAPI) تبدیل کند.
روی Windows، Linux و Mac کار می‌کند (نسخهٔ 0.1.0، هنوز در حال ساخت).

- آن را روی رایانهٔ خودتان نصب می‌کنید. وب‌سایت فقط راهنما و بارگیری دارد → <https://easy-web.tokyo/pl2pl/>
- اگر pl2pl نتواند چیزی را بازنویسی کند، آن را پنهان نمی‌کند. یک `TODO` (یادداشتی برای بعد) می‌گذارد و دلیلش را در گزارش می‌نویسد.
- هدف ما: بازنویسی میان هر چه بیشتر زبان‌های شناخته‌شده.

## امروز چه کارهایی می‌کند
| فرمان | کارش |
|---|---|
| `pl2pl php` | PHP (Laravel / Symfony) → FastAPI. بیشتر در [PHP.md](../../PHP.md) (ژاپنی) |
| `pl2pl web` | داخل یک پوشه را می‌بیند، Java، COBOL، PHP و Flask/Django را تشخیص می‌دهد و هر کدام را به ابزار مناسب می‌سپارد |
| `pl2pl ir` | (نسخهٔ آزمایشی) «مسیرها»ی PHP، Python و Java را به یک شکل مشترک درمی‌آورد و JSON، OpenAPI یا یک الگوی FastAPI می‌سازد. تبدیل PHP هم پیش از نوشتن، نوع‌ها، بدنهٔ تابع‌ها، مدل‌ها، میان‌افزارها و قالب‌ها را در این شکل می‌گذارد |
| `pl2pl watch` | نسخه‌های تازهٔ زبان‌ها و ابزارها را پیدا می‌کند و خودش خود را به‌روز می‌کند |
| `pl2pl cobol` | COBOL + JCL → GnuCOBOL (Linux) |
| `pl2pl omp` / `kokkos` / `gpu` | حلقه‌های C/C++ را سریع‌تر می‌کند (gpu نسخهٔ آزمایشی است) |
| `pl2pl cport` | کد C مخصوص UNIX را روی Windows و Linux قابل اجرا می‌کند |
| `pl2pl pyhpc` | محاسبات Python را با Numba سریع‌تر می‌کند |
| `pl2pl llm setup` | دستیار هوش مصنوعی (aruaru-llm) را نصب می‌کند. نصب واقعی را هنوز بررسی نکرده‌ایم |

## به‌روز شدن خودکار با نسخه‌های تازه
`pl2pl watch` را هر شب و هر صبح اجرا می‌کنیم.
1. بررسی می‌کند نسخهٔ تازه‌ای از زبان‌ها و ابزارها آمده یا نه (فهرست در `registry/ecosystem.toml` است).
2. با نسخهٔ تازه آزمون می‌کند. اگر آزمون‌ها بگذرند، «نسخهٔ پشتیبانی‌شده» را خودش به‌روز می‌کند.
3. اگر شکست بخورند، version-control (با کمک هوش مصنوعی) سعی می‌کند درستش کند.
4. اگر باز هم درست نشود، به نشانی‌های ایمیل و LINE ذخیره‌شده پیام می‌فرستد.

توجه: برای laravel، symfony، flask، django و چند مورد دیگر فعلاً فقط می‌گوید «نسخهٔ تازه آمده است».
در GitHub هم آزمون با تازه‌ترین نسخه‌ها هر شب و هر صبح خودکار اجرا می‌شود.

## روش استفاده
```
pl2pl php ./myapp --out ./out
pl2pl web ./project --target fastapi --out ./out
pl2pl ir ./project --out ./out --format openapi
```

## خوب است بدانید
- pl2pl محتاط است. اگر چیزی پرخطر به نظر برسد، دست‌نخورده می‌گذارد و دلیلش را می‌گوید. دربارهٔ سرعت نمی‌توانیم قول بدهیم.
- فقط نمونه‌های کوچک را آزموده‌ایم. برنامه‌های بزرگ و واقعی را هنوز امتحان نکرده‌ایم.

## گام‌های بعدی
- نوع‌ها و بدنهٔ تابع‌ها را هم در شکل مشترک بگذاریم و خروجی FastAPI را از آن عبور دهیم.
- PHP: بخش‌های Blade که به‌صورت کلاس نوشته می‌شوند.
- بررسی هشدارهای واقعی ایمیل و درست‌کردن خودکار با هوش مصنوعی.
- بررسی اجرا روی GPU (open-cuda / open-directx).

## تازه‌های v0.2.0
- ترکیب دلخواه خود را انتخاب کنید: `pl2pl web <dir> --backend <rust-axum|rust-poem|fastapi|mfastapi|rpoem|rporea> [--frontend bootstrap-ts|rust-wasm|none] [--db none|mysql|mariadb|postgres|sqlite] --out <dir>`. COBOL بازنویسی می‌شود؛ C، C++ و Fortran همان‌طور که هستند اجرا می‌شوند و وب آن‌ها را فرامی‌خواند.
- `pl2pl c2rust` (C و C++ ساده) و `pl2pl f2rust` (Fortran ساده) کد Rust می‌نویسند. `pl2pl cobol --os <linux|macos|unix|windows>` برای GnuCOBOL یک اسکریپت ساخت می‌سازد.

## تازه‌های v0.2.1 (2026-11-20)
- در `pl2pl web --backend` اگر `rpoem` / `rporea` را انتخاب کنید، هشدارهایی (به ژاپنی و انگلیسی) نشان می‌دهد: RPoem از پیش قابلیت‌های سازگار با Tauri و سازگار با WunderGraph Cosmo، tokio و WASM را دارد، پس آن‌ها را انتخاب نکنید؛ HTML5 و CSS3 به کار می‌روند اما کم نگه داشته می‌شوند؛ JavaScript، TypeScript، Node.js و REST طبق طراحی استفاده نمی‌شوند. چیزهایی که با `--also` افزوده شوند و از پیش در پشته باشند رد می‌شوند (کد خروج 2)؛ چیزهایی که هست اما هنوز پخته نیست، قابل انتخاب می‌مانند، همراه با یک هشدار.
- `pl2pl maturity [--repo DIR] [--llm URL] [--apply]` پختگیِ یادشده را با اجرای آزمون‌های سنجش می‌سنجد (دفتر: `registry/maturity.toml`). نظر هوش مصنوعی از aruaru-llm هرگز به‌تنهایی حکم را عوض نمی‌کند.
- با پشته‌هایی غیر از RPoem / RPoRea، `--also nodejs` (یا `next.js`) با یک اعلان پذیرفته می‌شود: سیاست «بدون Node.js» خود را بر کسی تحمیل نمی‌کنیم، اما توصیه‌اش هم نمی‌کنیم. جایگزین‌ها برای زبان انتخاب‌شده فهرست می‌شوند (RPoem / RPoRea + Reaxt، FastAPI + Jinja2، RS-Node.js و مواردی که خودمان بررسی نکرده‌ایم).
- مخزن‌های خواهر که با هم توسعه می‌یابند: Reaxt، RPoRea، RPoem، RMojo، open-cosmo، RS-TypeScript، RS-JavaScript، RS-Node.js و pl2pl. وقتی یکی تغییر کند، بقیه همان روز بررسی می‌شوند.
- `pl2pl info [ui|nojs|json|connect|shared] [--lang ...]` و `webpage/info.html` اصول طراحی RPoRea / RPoem را با مزایا و معایب به ۱۱ زبان توضیح می‌دهند.
- `COBOL_to` / `Java_to` اصلی نگه داشته شده‌اند (حذف نشده‌اند)؛ نسخه‌های ادغام‌شده در `converters/` خروجی یکسان دادند.

## تازه‌ها (از 2026-11-22 تا 2026-11-23)
- COBOL (`converters/cobol_to`): دستورهای `SORT` (`USING` / `GIVING`، `INPUT` / `OUTPUT PROCEDURE`، `RELEASE`، `RETURN`)، `MERGE`، `SEARCH` / `SEARCH ALL` و `INSPECT ... LEADING` / `CHARACTERS` اضافه شدند. شکل‌های کاربرد `COMP-3` و `COMP` هم اکنون خوانده می‌شوند.
- SQL توکار: `EXEC SQL` (مکان‌نماها، `FETCH`، `SELECT ... INTO`)، `WHENEVER`، متغیرهای نشانگر (از جمله شکل با کلیدواژهٔ `INDICATOR`)، `SQLSTATE`، `EXECUTE IMMEDIATE` و `PREPARE` / `EXECUTE ... USING`. Python تولیدشده واقعاً اجرا شد؛ سمت Rust فقط با یک کنترل‌گر آزمایشی بررسی شده است.
- `EXEC CICS` (حداقلی): `SEND TEXT` متن را نشان می‌دهد و `RETURN` / `ABEND` برنامه را پایان می‌دهند. فرمان‌های دیگر به صورت `TODO` می‌مانند. نقشه‌های صفحهٔ BMS بازسازی نمی‌شوند.
- Java (`converters/java_to`): ارجاع به متد، `Comparator`، `Collectors` و کلاس‌های ناشناس (همهٔ متدها نگه داشته می‌شوند). در سمت Rust عملیات List (`Vec`، `push`، دسترسی با اندیس، `for`) کار می‌کند و Rust تولیدشده برای spring، jaxrs، servlet و spark از `cargo check` گذشت.
- آزمایش روی Spring PetClinic REST (پروژه‌ای که از OpenAPI شروع می‌شود): شمار مسیرهای پیداشده از 1 به 37 رسید؛ Python تولیدشده 0 خطای نحوی دارد؛ پرس‌وجوهای مشتق‌شده (`Or`، `Like`، مقایسه‌ها، `OrderBy` و مانند آن) روی مخزن درون‌حافظه اجرا می‌شوند؛ برنامه را می‌توان وارد کرد (41 مسیر)؛ و نام‌های `this.field` یکسان شدند، به‌طوری که فراخوانی از کنترلر به سرویس و سپس مخزن می‌رسد.
- هنوز باز است: تولید مخزن و نگاشت‌گر MapStruct (فراخوانی‌ها در یک `TODO` می‌ایستند)، پایگاه دادهٔ واقعی، اجرای واقعی FastAPI تولیدشده، نقشه‌ها و فایل‌های CICS، و بدنه‌های Rust که Map یا Stream دارند. آزمون‌های pl2pl: 55 مورد گذشت.

## 2026-11-25 افزوده: c2rust، آرایه‌ها و break/continue

`pl2pl c2rust` اکنون این موارد را پشتیبانی می‌کند: آرایه‌های با طول ثابت (`int a[8] = {...};` و `double w[4];`؛ مقدارهای اولیهٔ کم‌تر با 0 پر می‌شوند)، خواندن و نوشتن با اندیس (`a[j + 1]` به `a[(j + 1) as usize]` تبدیل می‌شود)، `break;` و `continue;`، و `while (1)` که به `loop` تبدیل می‌شود. نمونه‌ای شامل مرتب‌سازی حبابی و `while (1)` با gcc و rustc روی WSL اجرا شد و خروجی‌ها کاملاً یکسان بودند (`1 2 3 4 5 7 8 9` / `6.00 12.00 9`). 56 آزمون واحد گذشت. هنوز نه: اشاره‌گرها، ساختارها (struct)، آرایه‌های دوبعدی، پاس دادن آرایه به تابع، و تبدیل ضمنی عدد صحیح و اعشاری (`k * 1.5` را باید به‌صورت `(double)k` نوشت).
